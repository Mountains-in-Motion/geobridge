# GeoBridge

### Landscape analysis in a changing world

**GeoBridge** is a collaborative platform at the **University of Bergen (UiB)** connecting researchers and students who use **Geographic Information Systems (GIS)** and **remote sensing (RS)** to investigate landscape dynamics and environmental change. The initiative brings together expertise across disciplines and strengthens collaboration with the **University of Amsterdam (UvA)**.

🌐 **[Visit the GeoBridge website](https://mountains-in-motion.github.io/geobridge/)**

## About the initiative

**The GeoBridge initiative began in March 2025 and concluded in July 2026**. The initiative supports knowledge exchange, education, and collaborative research on changes across the **biosphere, geosphere, and cryosphere**. Its interests include land-use and land-cover change, glacier evolution, vegetation shifts, and the spatial relationships between landscapes and biodiversity.

The community connects researchers and students from Earth Science, Biology, Geography, Physics, Archaeology, and related fields through shared geospatial methods and environmental questions.

## About this repository

This repository contains the source files and rendered pages of the GeoBridge website. The site is built with **[Quarto](https://quarto.org/)**, styled with **SCSS**, and published through **GitHub Pages**.

| File or directory | Purpose |
| :--- | :--- |
| `_quarto.yml` | Website configuration, navigation, theme, and output settings. |
| `index.qmd` and `about.qmd` | Homepage and background of the initiative. |
| `seminars.qmd`, `mssschedule.qmd`, and `joinmss.qmd` | Seminar information, schedule, and participation. |
| `storymaps.qmd` and `uavworkshop.qmd` | Workshop pages. |
| `teammembers.qmd`, `openprojects.qmd`, and `joinus.qmd` | Team, projects, and collaboration opportunities. |
| Individual profile `.qmd` files | Team member profiles. |
| `*.scss` | Website styles. |
| `img/` | Images, logos, and other visual assets. |
| `docs/` | Rendered website files for publication. |
